# Calculadora de Área do Retângulo

Projeto: exercício prático em Java para calcular a área de um retângulo via terminal.  
Autor: Cláudio

Descrição
---------
Programa simples que lê largura e altura do usuário pelo terminal, calcula a área (largura × altura) e exibe o resultado formatado com duas casas decimais.
